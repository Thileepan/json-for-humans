Deterministic magic. No black boxes.

Every transformation is a readable rule, not a guess — the same input always gives the same output. Here's what the engine does the moment you paste.

five views

Read it your way

Document for reports, Cards for overviews, a sortable Table for arrays (with CSV export), Tree for structure, Raw for the purists. Same data, one click apart.

smart formatting

Speaks fluent JSON

user_id → User ID, PAYMENT_PENDING → Payment Pending, true → Yes, timestamps → real dates in your timezone, 0.85 → 85%. Acronyms like URL, UUID and OTP survive intact.

compare

Spot the difference

Paste two versions and get plain-English sentences: “Payment Status changed from Pending to Completed.” No more eyeballing diffs at 2 a.m.

custom schema

Your data, your labels

Map status: 2 to “Approved”, attach currencies, rename anything — with nested paths like orders[].amount. Schema always wins over auto-detection.

export

Share it readable

Copy or download as plain text, Markdown, script-free HTML, CSV or a print-ready page. Everything is escaped; nothing executable ever leaves the exporter.

search & filters

Find anything, hide the noise

Search names and values across any nesting depth. Hide nulls, empties and technical IDs when you only want the story, not the plumbing.

Private by design, not by promise

You paste production data into this tool. We built it so you never have to trust us with it.

No backend A static page and nothing else. There is no server to send your JSON to.
No network calls Parsing, formatting, comparing and exporting all happen in your browser tab.
No tracking No analytics, no cookies, no fingerprinting. Not "anonymized" — absent.
No storage Your JSON lives in page memory and dies with the tab. Settings persist only if you opt in.
Works offline Once loaded, pull the network cable. Everything keeps working.
Open source MIT-licensed and auditable. Don't take our word for any of this — read the code.
